## Oregon Trail Accessibility Mod

Download **OregonTrailAccessibilitySetup** below and run it. Setup downloads the game from the Internet Archive and DOSBox Staging from GitHub, installs the mod, and can add Start menu and desktop shortcuts.

- Turn your screen reader off or put it to sleep while playing; the mod speaks with Windows voices.
- Press F1 in the game for help. The full key guide is in the Read me shortcut.

See the README for details.
